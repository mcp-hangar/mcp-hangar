`mcp-hangar init` now writes an entry a client can start from any directory: the command is an absolute path to the installed launcher, and the generated config names an absolute `event_store.path` (under `$XDG_STATE_HOME` or `~/.local/state/mcp-hangar`). The saga state and approvals databases follow it, so starting Hangar no longer creates `data/` in whatever directory the client spawned it from (#1772).
