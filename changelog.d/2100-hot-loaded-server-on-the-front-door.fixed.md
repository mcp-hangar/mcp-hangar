**core:** `hangar_load` on a front door (`tool_access.mode: front_door`) now says that the front door does not serve the server it loaded. The front door lists and routes only the servers the configuration declares, so a hot-loaded server's tools were never listed there and a flat call of one answered `-32601`, while the load answered `loaded` with no hint of it. The answer, and an `already_loaded` answer for a hot-loaded server, now carry a warning saying so and naming the way to serve the server there: declare it in `config.yaml`. The load itself is unchanged, and an `egress` gateway answers as before.
