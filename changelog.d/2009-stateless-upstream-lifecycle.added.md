**core:** Hangar speaks the 2026-07-28 stateless lifecycle (SEP-2575) to an HTTP upstream that serves it. The start probes `server/discover` first, the way the SDK client's `mode="auto"` does. An upstream that names 2026-07-28 is never sent `initialize`. Every request to it carries the `MCP-Protocol-Version` header, equal to the protocol version, client info and client capabilities in its `_meta`, and no `Mcp-Session-Id`. A -32022 refusal that offers 2026-07-28 is retried once. Any other answer falls back to the `initialize` handshake, so upstreams on 2025-11-25 and earlier are unchanged. The `io.modelcontextprotocol/clientCapabilities` key is now always sent on a modern request (`{}` when Hangar declares nothing), because a stateless upstream refuses a request without it.
