**observability:** A cold start now shows how long the launch itself took: each launcher opens an `mcp_server.launch` span around spawning the process, running the container or opening the HTTP transport. It carries `mcp.server.id` and the server's own `mcp.server.mode`, the same value the cold start metric reports, so a docker server reads `docker` although `ContainerLauncher` runs it. A failed launch ends ERROR like every other Hangar span, and an expected refusal does not.
