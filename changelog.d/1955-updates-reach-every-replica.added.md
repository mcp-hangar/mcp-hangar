**core:** a server's configuration update now reaches every replica without a restart. The fleet projection applies `McpServerUpdated` for every server, not only key-pinned ones. A changed endpoint or `tls` block replaces the replica's copy with a fresh one built from the shared row, and the old copy is retired. A changed description, env, idle TTL or health-check interval is applied in place. Neither publishes anything. A group that has the server as a member follows the replacement. A server the configuration file declares still changes only when its replica reloads the file. `PUT /mcp_servers/{id}` now accepts a new endpoint for a server without a peer identity, which needs only `mcp_servers:write`.
