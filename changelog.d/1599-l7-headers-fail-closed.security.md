**security:** Every L7 `Mcp-Param-*` header check now fails closed on an unknown validation state. A header mapping that does not state validation ran no longer consults header rules; before, a mapping without the status key was read as validated. A request carrying a checked header beside one dropped as unchecked is now recorded as such, so the verdict's reasons carry "header rules not consulted" while the checked header still decides. `headers.param_validation.required` now refuses any request carrying an `Mcp-Param-*` header that did not reach the selector, `hangar_call` included; before, it refused only on the front door's failed pre-dispatch listing (#1599).
