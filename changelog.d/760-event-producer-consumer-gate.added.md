**ci:** a gate on events whose handler nothing feeds. `DetectionEnforcementHandler` -- which suspends sessions and stops servers -- is subscribed to `DetectionRuleMatched` in bootstrap, and nothing in `src/` constructs that event: the enforcement path is wired end to end except for the step that would ever start it. No test, type check or lint could see that, because each half is correct on its own. Four such pairings are now declared with their reason (`DetectionRuleMatched` and `BehavioralDeviationDetected` belong to the deliberately unshipped anomaly detection; `EgressBlocked` and `TaskInputRequired` outlived the code that emitted them), and a new one fails the build unless it is declared too. The 18 event classes with neither a producer nor a consumer are baselined the same way, so the vocabulary can shrink but not grow -- that list is how a codebase accumulates names for features nobody built
