**core:** three log lines no longer carry an upstream's raw output above DEBUG. A stdout line that is not JSON (`stdio_client_malformed_json`), an SSE data line that is not JSON (`http_client_sse_invalid_json`) and a stdio process's stderr when it exits (`stdio_client_process_stderr`) used to log up to 100 or 2000 characters of that text at ERROR, WARNING or INFO, where the telemetry data contract allows a summary only. They now log the text's size at the same level and the text itself, still bounded, in a `*_text` line at DEBUG.
