**core:** a new permission, `mcp_servers:peer_identity`, guards declaring a peer identity (`tls.peer_identity`) on a server and deleting a server that has one (ADR-030). `admin` holds it through `*:*` and `kubernetes-operator` is granted it. `developer` and `provider-admin` are not, so `mcp_servers:write` and `mcp_servers:lifecycle` no longer suffice to remove a key-pinned server. A discovery source is refused in every authentication mode. With authentication off, the check allows.
