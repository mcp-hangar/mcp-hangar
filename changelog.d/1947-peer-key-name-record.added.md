**core:** the SQLite and PostgreSQL configuration stores gain the peer-key name record (`peer_key_names`, ADR-030 §9). A server's name and `key_ref` are recorded there in the same transaction as its configuration row. The entry outlives the server, so a deleted key-pinned server cannot be registered again under its name without the same `key_ref`, and one `key_ref` names one server. A gateway without durable storage refuses to register a server with a peer identity.
