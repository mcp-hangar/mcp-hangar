**core:** Hangar now sends the SEP-2243 standard request headers on every HTTP request to an upstream: `Mcp-Method` from the JSON-RPC method, and `Mcp-Name` from the tool or prompt name or the resource URI on `tools/call`, `prompts/get` and `resources/read`. A name that is not plain printable ASCII is sent in the `=?base64?...?=` form, so a CR or LF in it never reaches a header, and an operator header of the same name in `extra_headers` no longer decides these values. Mirroring a tool's `x-mcp-header` parameters as `Mcp-Param-*` headers follows separately.
