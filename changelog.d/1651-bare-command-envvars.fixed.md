A bare `mcp-hangar` (no subcommand) now reads the same environment as `mcp-hangar serve`: `MCP_HTTP_HOST`, `MCP_HTTP_PORT`, `MCP_LOG_LEVEL` and `MCP_JSON_LOGS`. The implicit serve called the command's function with its Python defaults, so a gateway started as `MCP_MODE=http MCP_HTTP_HOST=10.1.2.3 mcp-hangar` listened on loopback and port 8000 instead of the address that was asked for.
