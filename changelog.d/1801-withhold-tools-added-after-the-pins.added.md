`tool_projection.new_tools: withhold` (per server, default `allow`) withholds a tool that appears on the server after its pins were taken: it is not listed on any surface, a call of it is refused like a withdrawn tool, and one `ToolAdmissionRequested` event names the server, the tool and the digest of the definition waiting to be approved. Pinning the tool (`mcp-hangar pin --write`, or a pin in the config) admits it, for all tenants or for the tenant that pinned it. A server with no pins has no baseline and withholds nothing, and prompts and resources are not affected.
