**core:** a server that discovery registered, that the configuration file then took over and that a reload later dropped is discovered again, as after a restart. Discovery still held the name after the reload: as tracked, so every scan read the source's report as unchanged and skipped it, or as static, when the file had declared it at boot. The server stayed gone until the next restart, although its source still reported it. A reload now has discovery forget each server it removes, so the next scan registers the server, or holds it for approval, while the source reports it. A server the source no longer reports stays gone, and a server created again under the name before discovery hears of the reload is left alone.
