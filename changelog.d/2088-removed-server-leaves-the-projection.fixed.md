**core:** In `tool_access.mode: front_door`, a server that leaves the fleet now leaves `tools/list` too, and listing clients get `notifications/tools/list_changed`. Before, a server removed by a config reload or by `DELETE /api/mcp_servers/{id}` (or a discovery delete) stayed listed, though a call of its tools was already refused. A server added back under the same name is listed again once it starts, still under the withdrawals and pins its name had. When two servers exposed the same tool name, the name was hidden from both; once one of them is removed, the name is listed again and routes to the server that stayed.
