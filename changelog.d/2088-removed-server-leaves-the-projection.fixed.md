**core:** In `tool_access.mode: front_door`, a server that leaves the fleet now leaves `tools/list` too, and listing clients get `notifications/tools/list_changed`. Before, a server removed by a config reload or by `DELETE /api/mcp_servers/{id}` (or a discovery delete) stayed listed, though a call of its tools was already refused. A server registered again under the same name is listed again at once, with its last known tools and under the withdrawals and pins its name had, whether or not it is started on that replica; the first call starts it, as before, and its start replaces the entries. When two servers exposed the same tool name, the name was hidden from both; once one of them is removed, the name is listed again and routes to the server that stayed.
