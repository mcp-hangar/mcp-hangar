The Makefile no longer carries targets that could not run: `check-boundary` (its script was removed), `workspace-setup`, `workspace-start`, `workspace-stop` and `workspace-status` (their script is not in this repository) and `proto-gen`, `proto-lint`, `proto-breaking` and `setup-proto` (there is no `api/` directory), which also made `make lint` fail on any machine without `buf`. `make lint` is now `make lint-core`, `make setup` is `make setup-core`, and `make dev` starts without `--config` unless `CONFIG=path` is given, instead of reading a `config.max.yaml` that does not exist.
