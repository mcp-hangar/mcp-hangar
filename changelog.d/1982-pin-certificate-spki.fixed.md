**core:** a key pin is now taken over the `SubjectPublicKeyInfo` exactly as the upstream's certificate encodes it, as ADR-030 defines it. Core re-encoded the key first, which turned an EC key with explicit curve parameters, the default of the `openssl` macOS ships, into its named-curve form, so a pin computed with `openssl x509 -pubkey | openssl pkey -pubin -outform der | openssl dgst -sha256` was refused as `upstream_peer_key_mismatch`. Pins of RSA and named-curve EC keys are unchanged.
