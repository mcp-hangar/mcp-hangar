**core:** a key-pinned server's key list or endpoint now changes on every replica without a restart (ADR-030 §8). The fleet projection applies `McpServerUpdated`. It compares the stored row with what the local copy's live client was built from, and when they differ it replaces the copy with a `COLD` one built from the row. The old copy is retired: it refuses calls and a start under way, and its connection is closed in the background. When the row cannot be read, the copy is retired and calls are refused until a later read succeeds. A plain row under a name in the peer-key name record is refused on registration and on update. Updates of servers that are not key-pinned are unchanged.
