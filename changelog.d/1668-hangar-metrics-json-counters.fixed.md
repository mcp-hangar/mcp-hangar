`hangar_metrics` JSON reports what the counters hold. Per-server `invocations`, `errors` and `avg_latency_ms` and each tool's `errors` were always 0, `count` took the last histogram sample instead of the total, and `discovery.*.cycles` held a Unix timestamp, because the code matched substrings of metric names that no metric has. It now reads the named collectors: `mcp_hangar_tool_calls` (every call, errors by status), the tool-call duration histogram (mean latency), `mcp_hangar_discovery_cycles` and `mcp_hangar_errors`.
