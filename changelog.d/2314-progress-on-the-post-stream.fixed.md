**core:** relay the `notifications/progress` an HTTP upstream sends on the SSE body of a `tools/call` POST response to the caller whose token it carries, as each event arrives (a compressed body is relayed once it is read); a stateless (2026-07-28) upstream has no standing GET stream, so a long call through the gateway showed its caller no progress at all. Only progress carrying the token that call sent is relayed; any other token on that stream is dropped.
