**core:** `hangar_call` now refuses a tool that the flat projection withholds for its `x-mcp-header` annotations. That covers an invalid annotation, and a `header_exposure` block with `on_violation: withdraw` or `refuse_boot` on the server or a group that owns it. Before, such a tool was hidden from the flat listing but could still be called through `hangar_call`. The refusal reads `ToolHeaderWithheldError` and is logged as `batch_call_refused` from the `header_exposure` gate, with the reason the flat path counts. A tool whose schema is not in the catalogue after its cold start is refused as `schema_unknown` when a block that withholds governs it.
