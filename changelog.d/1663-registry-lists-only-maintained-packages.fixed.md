`mcp-hangar init` and `add` no longer write packages that do not run. `fetch` and `git` now install from their official PyPI distributions with uvx (their npm names are a 404). `github`, `postgres`, `slack`, `puppeteer`, `brave-search`, `google-maps` (npm: no longer supported) and `sqlite` (never published to npm under that name) are removed from the registry, and with them the `data` bundle. A weekly check resolves every entry against npm and PyPI.
