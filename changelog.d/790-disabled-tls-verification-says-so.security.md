Disabling certificate verification for an upstream now logs a warning naming the endpoint. The setting changed meaning in this release: until 2.5.0 `tls.verify_ssl: false` was accepted and silently discarded, so a configuration carrying it did nothing, and now it does exactly what it says. Whoever wrote that line may no longer be reading, and the value was previously visible only as a field on an ordinary info line among dozens. Trusting a private CA through `tls.ca_cert_path` is verification and stays quiet.
