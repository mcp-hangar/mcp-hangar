**core:** the `task_relay_mint_failed` warning no longer carries the text of a malformed upstream task handle. It now logs the exception's bounded type as `error_type` with its existing identifiers, and the full text, which echoes the handle, moves to an adjacent `task_relay_mint_failed_detail` DEBUG line, as the data-handling contract requires for log lines at INFO and above (#1276). The message returned to the caller is unchanged.
