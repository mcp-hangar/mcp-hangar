`mcp-hangar why [EVENT_ID] [--last N] [--server S] [--db PATH]` prints the latest refusals recorded in the event store: when, which server and tool, the gate and its reason, and for a digest mismatch the expected and the observed digest; an event id (or its first characters) shows one event in full. It opens the SQLite store read-only, so it works while a gateway your client started holds it open, and writes nothing. The store is the one the config names (`event_store.path`, or `persistence.sqlite`), else the one `init` creates.
