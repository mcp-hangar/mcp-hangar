**core:** In `tool_access.mode: front_door`, the boot warm-up now counts as running from before its thread starts, and so before the gateway accepts a request. Before, it was marked from inside the thread, and a `tools/list` or `server/discover` that arrived in the moment before the thread ran answered only the `hangar_*` tools at once instead of waiting for the upstream catalogue. A warm-up thread that fails to start, or a warm-up that raises, still ends the wait, and an `egress` gateway or a front door with no configured server is never marked as warming.
