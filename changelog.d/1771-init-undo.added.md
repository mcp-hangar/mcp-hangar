`mcp-hangar init --undo` puts every MCP client config back byte-for-byte as it was before `init` first changed it (a file `init` created is removed), and refuses, listing the files and how many lines differ, when a file was edited since `init` wrote it unless `--force` is given. To make that possible `init` now keeps one pre-Hangar copy of each client file in the Hangar state directory (`$XDG_STATE_HOME/mcp-hangar/init-backups`, with an `init-manifest.json`) and no longer writes a `<name>.backup.<timestamp>.json` beside the file on every run, which left backups inside the project directory.
