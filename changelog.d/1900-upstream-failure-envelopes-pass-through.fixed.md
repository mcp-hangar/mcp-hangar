An upstream tool result that reports its own failure (`isError: true`) now reaches the caller as the upstream sent it. A front-door `tools/call` returns the whole result, including its `_meta` envelopes (the structured tool-failure classification of SEP-3313, the structured authorization denial of SEP-2643), `structuredContent` and every content block, where it used to return only the text. A `hangar_call` result entry for such a call carries the same result as `upstream_result`, beside the unchanged `success: false` and `error`.
