**security:** a configuration file that does not exist now stops the gateway instead of booting a built-in demo configuration. `mcp-hangar --config /typo.yaml serve`, an `MCP_CONFIG` naming a missing file, a `config_path` passed to `bootstrap()` or `Hangar.from_config()`, and a start with no file anywhere used to log `config_not_found_using_default` at INFO and serve a `math_subprocess` backend with every `hangar_*` tool and none of the operator's pins, policies or auth. Every entry point now exits 1, or raises `MissingConfigFileError`, with a message naming the path and where it came from; with no file anywhere it says to run `mcp-hangar init`. A path that is a directory or unreadable is refused the same way (#1650).
