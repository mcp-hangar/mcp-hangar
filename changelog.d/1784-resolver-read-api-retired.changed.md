**core:** `decide()` is now the only way to read an access decision. `ToolAccessResolver` keeps its registration API and loses `resolve_effective_policy`, `is_allowed`, `is_tool_allowed`, `filter_tools` and `filter_tool_dicts`, whose loose-string scope arguments let a server id land in the tenant slot.
