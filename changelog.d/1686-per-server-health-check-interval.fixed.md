A server's `health_check_interval_s` is honoured. The value was stored and reported, but the health-check worker swept every 60 seconds and scheduled each next check from its own interval, so a server declaring 5 seconds was checked every 60. The worker now wakes as often as its most frequent server needs (never faster than once a second) and schedules each server on its own interval. A server at the default 60 follows the worker's pace as before, and with every server at 60 the sweep is unchanged.
