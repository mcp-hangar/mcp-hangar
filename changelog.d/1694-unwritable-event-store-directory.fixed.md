An event-store directory that exists but is not writable no longer crashes startup with a bare SQLite traceback. SQLite reports it as `OperationalError`, not `OSError`, so neither `allow_memory_fallback` nor the error naming the path ran. With the fallback the gateway starts on memory with a degraded posture and a warning; without it, it exits with a message naming the path. This is the stock image under `--read-only`.
