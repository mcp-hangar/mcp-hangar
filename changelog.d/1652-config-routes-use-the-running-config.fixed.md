`GET /api/config/diff` and `POST /api/config/backup` act on the configuration file the gateway was started with, as `/api/config/reload` already does. They no longer accept `config_path` (a query parameter on the diff, a body field on the backup): the path made the diff load, and the backup copy, any file the process could read. Without it they resolved `MCP_CONFIG` or `./config.yaml` and ignored `--config`, so a gateway started with `--config X` backed up the wrong file.
