A call that an enforced L7 egress policy refuses (a deny, or a requireApproval nobody granted) no longer starts a COLD server first. The batch executor started the target before the aggregate evaluated the policy, so a denied call spawned the server and ran `initialize` and `tools/list` upstream, and left it READY; the refusal, its event and its record are unchanged. A call with a pin check still to run, and a policy in Audit mode, start the server as before.
