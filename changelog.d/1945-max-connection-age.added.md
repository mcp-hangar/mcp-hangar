**core:** a key-pinned server (ADR-030) replaces its connection pool every `tls.max_connection_age`. The default is one hour; give a number of seconds or a duration such as `90s`, `30m` or `1h`. After each replacement every connection handshakes again against the current key list, so a connection verified once cannot keep serving indefinitely. A request in flight finishes on the old pool before that pool is closed. The MCP session survives the replacement, and the GET stream re-opens on the new pool at once. `tls.max_connection_age` on a server without `tls.peer_identity` is refused at load.
