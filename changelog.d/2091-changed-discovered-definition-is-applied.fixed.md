**core:** A discovered server whose definition changes (an edited file, changed labels or annotations) is replaced with the new definition on the next discovery cycle, after its calls in flight finish (at most 30 seconds, as a graceful reload waits). It used to be refused every cycle with `McpServer already exists`, and then removed and created again once its TTL ran out. The change passes every check a new registration does, and only a server discovery registered is ever replaced. A change that is refused leaves the running definition running and is logged once as `discovery_change_not_applied`. With `auto_register: false`, or when the change fails validation and is quarantined, it waits for approval while the running definition keeps running, and approving it now applies it.
