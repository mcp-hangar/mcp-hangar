**cli:** `mcp-hangar init` moves the MCP servers your clients already have behind Hangar. For Claude Code (user and project files) and Cursor, it does three things. It reads the `mcpServers` you already list. It starts each server once and pins every tool it serves. It writes each server that answered into the Hangar config under its own name, with its `args` and `env`. In the client file, the moved entries are then replaced by the single `mcp-hangar` entry. A server that does not start stays in its client file, and the summary names it with the reason. Interactively, you can leave any server where it is; `-y` moves every server that starts. The default bundle is installed only when no client lists servers. A config holding `env` values is readable by its owner only. `init --undo` restores the client files as they were. With `--skip-test`, nothing moves, because moving a server needs its first start.
